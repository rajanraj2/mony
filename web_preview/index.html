🚀 Mony App Verification Guide

Mony is built on Flutter 3.22+ with a 100% offline-first Drift SQLite database, Riverpod 2 state management, and an integrated MCP 2 protocol server.

📱 1. Testing on Android / iOS / Desktop

Clone and run directly on your phone or emulator:

git clone https://github.com/rajanraj2/mony.git
cd mony
flutter pub get
flutter run # Android / iOS / Mac
flutter run -d chrome # Web Browser

🤖 2. MCP 2 AI Tool Calling

Connect any MCP client (Claude Desktop, cursor, or local agent) to Mony's JSON-RPC server on port 7432:

{
  "mcpServers": {
    "mony": {
      "command": "dart",
      "args": ["run", "lib/main.dart"]
    }
  }
}

⚡ 3. Automated CI Workflow

GitHub Actions runs lints, formatting, and full unit test coverage on every Pull Request:

flutter test --coverage
flutter analyze --no-fatal-infos
